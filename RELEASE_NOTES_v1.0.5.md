## ✨ New Features

### 📊 Team Analytics Dashboard (Team Tier & Above)
**Location**: Tool Window → Team Analytics

**Features:**
- Real-time test health metrics with visual cards
- Key metrics tracked:
  - Total tests with growth trends
  - Pass rate percentage with improvements
  - Flaky test count with reduction tracking
  - Average execution time with optimization gains
  - Team productivity score (0-100)
  - Code coverage percentage
- Recent team activity feed
- One-click upgrade prompt for free users
- Professional styling with color-coded trends

**Value Proposition:**
- Save 20+ hours/month per team
- Identify problematic tests at a glance
- Track team productivity improvements
- Make data-driven decisions about test strategy

**Value Proposition:**
